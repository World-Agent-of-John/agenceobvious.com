Règles de confidentialité

Dernière mise à jour : 9 novembre 2026

Agence Obvious installe pour chaque client un espace privé, sur un serveur qui lui est dédié, où travaillent ses agents IA. Cette page dit quelles données nous traitons, pourquoi, où elles se trouvent et quels sont vos droits.

Responsable du traitement

Agence Obvious. Contact : john@agenceobvious.com.

Les données traitées

  • Votre compte : adresse email, mot de passe (stocké sous forme hachée), passkeys (clés publiques seulement), journal de sécurité (connexions, adresse IP).
  • Vos données de travail : ce que vous confiez à votre espace, par exemple les comptes rendus de vos appels et les informations utiles sur vos prospects.
  • Vos données Google, seulement si vous connectez votre compte Google : voir la partie suivante.
  • Le formulaire de contact du site : votre nom, votre email, votre activité et votre message. Ils servent uniquement à vous répondre : ils passent par notre serveur d'automatisation (OVHcloud), qui n'en garde aucune copie, et arrivent dans notre messagerie (Google Workspace), où ils restent le temps de l'échange. Vous pouvez demander leur effacement à tout moment.

Les données Google

Quand vous connectez votre compte Google depuis votre espace, nous demandons trois accès :

  • votre adresse email, pour afficher le compte connecté ;
  • la gestion des événements de votre agenda, pour créer les rendez-vous que vous avez validés ;
  • l'envoi d'emails depuis votre adresse, pour envoyer les messages que vous avez validés. Cet accès ne permet pas de lire votre boîte de réception.

Aucun rendez-vous n'est créé et aucun email n'est envoyé sans votre validation dans votre espace. L'autorisation donnée par Google est conservée chiffrée dans votre espace : elle n'est jamais affichée, jamais transmise à un modèle d'IA ni à un tiers. Les données reçues des API Google ne servent ni à entraîner des modèles d'IA, ni à la publicité, et ne sont jamais vendues.

L'utilisation et le transfert vers toute autre application des informations reçues des API Google par Agence Obvious respectent le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Vous pouvez retirer cet accès à tout moment, depuis votre espace (Connexions) ou depuis votre compte Google (myaccount.google.com/permissions).

Où sont vos données

Chaque client a son propre serveur chez OVHcloud, isolé de ceux des autres clients, dans la région convenue avec lui. Les sauvegardes sont chiffrées.

Les services qui interviennent

  • OVHcloud : hébergement des serveurs.
  • OpenAI : les agents utilisent le modèle de votre propre abonnement ChatGPT. Ce que l'agent traite pour vous (un compte rendu, un message à valider) passe par OpenAI.
  • Telegram : si vous échangez avec votre agent par Telegram, vos messages passent par ce service.
  • Google : seulement si vous connectez votre compte, comme décrit plus haut, et notre propre messagerie (Google Workspace), qui reçoit les messages du formulaire de contact.

Durée de conservation

  • Un prospect sans rendez-vous depuis 12 mois est anonymisé : son nom, les comptes rendus et les liens d'enregistrement sont effacés, seules restent des données sans nom (issue de l'appel, notes, objections).
  • L'accès Google est conservé jusqu'à ce que vous le retiriez.

Vos droits

Vous pouvez demander l'accès à vos données, leur rectification, leur effacement, leur portabilité, ou vous opposer à un traitement, en écrivant à john@agenceobvious.com. Vous pouvez aussi adresser une réclamation à la CNIL (cnil.fr).
